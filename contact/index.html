앱 오류, 설명의 수정, 새로운 제안은 프로젝트 저장소에서 알려주세요.

앱에 관한 문의

문의하려는 앱의 GitHub 저장소에서 Issues 탭을 확인해 주세요. 같은 문제가 이미 등록되어 있다면 해당 글에 정보를 보태 주시면 됩니다. Issues 기능이 꺼져 있다면 운영자 프로필에서 공개된 연락 방법을 확인해 주세요.

Superword↗ADF PDF Reorder↗GeminiChat Studio↗Aether Weather↗EasyUpload↗Gemini Argon Radar↗

함께 적어 주시면 좋은 내용

앱 이름, 사용한 기기와 브라우저, 문제가 발생한 순서, 기대한 결과와 실제 결과를 알려주세요. 화면을 첨부할 때는 API 키, 파일 내용과 개인정보를 가려 주세요. 공개 저장소의 문의는 다른 사람에게도 보일 수 있습니다.

블로그 운영 및 콘텐츠 문의

블로그 운영 관련 문의는 운영자의 GitHub 프로필을 통해 공개된 연락 경로를 확인해 주세요. 별도 이메일 수집 양식은 운영하지 않습니다.

운영자 프로필 확인↗

오류 제보 시 주의 사항

개인 계정의 비밀번호나 API 키를 요청하지 않습니다. 민감한 정보가 포함된 원본 파일을 공개 문의에 첨부하지 마세요.
