# 작은 도구들 블로그 관리

이 저장소의 루트에서 `junhyuk.site`를 제공하며, 블로그 소스는 이 폴더에 있습니다.

글은 `content.mjs`, 사이트 주소 및 애드센스 설정은 `site.config.mjs`에서 수정합니다. Node.js 24로 `npm run build`와 `npm run check`를 실행한 뒤, `dist`의 내용을 저장소 루트에 복사하고 변경사항을 `main`에 올리면 GitHub Pages에 반영됩니다. `CNAME`과 `ads.txt`도 빌드 결과에 포함됩니다.

애드센스 스크립트는 모든 페이지에 포함되어 있으며, 개별 광고 단위는 현재 비활성화되어 있습니다. 애드센스 심사 승인과 실제 동의 관리 구성을 완료한 후에만 광고 설정을 켜야 합니다.
