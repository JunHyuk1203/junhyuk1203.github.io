PRIVACY POLICY

개인정보처리방침

시행일: 2026년 10월 27일 · 운영자: JunHyuk1203

1. 적용 범위

이 방침은 작은 도구들 블로그에 적용됩니다. 링크로 연결된 앱, GitHub, Google 등의 외부 서비스에는 각 서비스의 개인정보처리방침이 적용됩니다.

2. 이 블로그에서 처리하는 정보

블로그는 회원 가입, 댓글, 파일 업로드와 문의 양식을 운영하지 않습니다. 검색어는 현재 페이지 안에서 글을 찾는 데만 사용하며 별도로 서버에 전송하거나 저장하지 않습니다. 글 링크 복사 기능은 사용자가 버튼을 누를 때 해당 글의 주소를 클립보드에 복사합니다.

3. 접속 기록과 호스팅

웹페이지 제공과 보안 운영을 위해 호스팅 사업자와 네트워크 제공자가 IP 주소, 요청 주소, 접속 시각, 브라우저 정보 등의 기술 정보를 처리할 수 있습니다. 실제 보관 기간과 처리 위치는 사용하는 호스팅 사업자의 정책에 따릅니다. 운영자는 이 블로그에서 별도의 분석용 쿠키나 추적 스크립트를 추가하지 않습니다.

4. 광고 및 쿠키

현재 Google AdSense 광고와 분석 도구를 활성화하지 않았으며, 블로그 자체에서 광고용 쿠키를 생성하지 않습니다. 향후 광고를 도입하면 사용하는 광고 서비스와 쿠키, 선택 방법을 이 페이지에 반영합니다.

Google 광고 서비스의 데이터 이용에 관한 설명은 Google 광고 정책 안내에서 확인할 수 있습니다.

5. 외부 앱과 API 키

소개된 앱에서 입력하는 API 키, 학습 자료, 문서와 기타 데이터는 이 블로그가 수집하지 않습니다. 앱을 실행하기 전에 해당 앱의 저장 방식과 외부 전송 여부를 확인해 주세요. GitHub에 문의를 남기는 경우 GitHub의 계정 및 공개 게시 정책이 적용됩니다.

6. 문의와 변경

개인정보 관련 문의는 문의 페이지의 운영자 연락 경로를 이용해 주세요. 운영 방식이 달라지면 이 방침과 시행일을 업데이트합니다.
