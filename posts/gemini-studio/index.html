모델 선택과 대화를 한 공간에서

GeminiChat Studio는 사용자의 Gemini API 키로 대화하는 웹 앱입니다. API 키가 지원하는 모델 목록을 불러오고, 선택한 모델과 스트리밍 방식으로 대화할 수 있습니다. 모델별 응답을 직접 살펴보거나 자주 쓰는 생성 옵션을 조정하고 싶은 경우에 활용할 수 있습니다.

대화 이후의 작업도 이어서

README에는 Markdown 렌더링, 코드 하이라이팅과 복사, 여러 대화 세션 관리, 세션 검색, Markdown 내보내기가 안내되어 있습니다. 대화에서 받은 코드나 메모를 다른 문서로 옮기는 작업에 유용한 구성입니다. Temperature, 출력 토큰 수, 시스템 지시문도 조정할 수 있습니다.

Google 검색 연동 기능을 사용할 때는 답변에 붙은 출처를 직접 확인하세요. 검색 기능의 지원 여부와 사용 가능한 모델은 API 계정과 서비스 제공 상황에 따라 달라질 수 있습니다.

처음 실행할 때

  1. Google AI Studio에서 본인 계정의 Gemini API 키를 준비합니다.
  2. 앱에 키를 입력하고 불러온 모델 목록에서 사용할 모델을 선택합니다.
  3. 짧은 질문으로 응답을 확인한 다음 생성 옵션을 조정합니다.
  4. 보관할 대화는 Markdown으로 내보내고, 공용 기기에서는 키와 기록을 정리합니다.

키와 비용은 직접 관리해야 합니다

저장소 안내에 따르면 API 키는 브라우저 localStorage에 저장되고 Google API로 직접 요청을 보냅니다. localStorage는 같은 브라우저 프로필을 사용하는 사람이 접근할 수 있는 저장 공간이므로, 공용 PC에는 키를 남기지 마세요. API 사용량과 요금은 Google 계정에서 확인하고 사용 한도를 설정하는 것이 좋습니다.

대화가 실패하면 확인할 순서

선택한 모델에 접근 권한이 있는지, API 키가 유효한지, 요청 한도를 초과하지 않았는지 차례대로 살펴보세요. 이 앱의 화면이 열리는 것과 API 호출이 성공하는 것은 서로 다른 단계입니다. 오류 메시지에 포함된 키나 개인 대화 내용을 공개 게시물에 그대로 붙이지 않도록 주의하세요.

질문과 옵션을 조정하는 방법

긴 문서를 요약할 때는 먼저 원하는 길이와 형식을 명시하고, 중요한 사실을 원문과 대조해 달라고 요청해 보세요. 결과가 너무 길거나 짧으면 출력 토큰 설정과 요청 문구를 함께 점검할 수 있습니다.

모델을 바꾸어 비교할 때는 같은 질문과 비슷한 설정으로 시험해야 차이를 살피기 쉽습니다. 답변 속도나 사용 가능 여부는 선택한 모델과 서비스 상태에 따라 달라집니다.
