Superword

Gemini를 사용하는 변환 도구입니다. 생성 결과를 확인한 뒤 학습 자료로 사용하세요.

단어를 외우기 전에 해야 하는 일

영어 단어장을 디지털 카드로 바꾸려면 단어와 뜻을 하나씩 입력해야 합니다. 책의 예문까지 담으려면 준비 과정은 더 길어집니다. Superword는 이 입력 단계를 줄이는 데 초점을 맞춘 도구입니다. 단어가 담긴 텍스트나 사진을 입력하면 Gemini를 이용해 학습 자료를 정리하고, 굿노트 스터디 세트용 CSV로 내보냅니다.

이 도구가 제공하는 것은 완성된 학습 진도 관리가 아니라 카드 제작을 위한 변환 과정입니다. 이미 사용 중인 굿노트 학습 흐름을 유지하면서, 자료를 준비하는 부분에 활용할 수 있습니다.

텍스트와 사진, 두 가지 입력

복사할 수 있는 단어 목록은 텍스트로 붙여 넣고, 종이 자료는 사진이나 스캔 이미지로 올릴 수 있습니다. README에 따르면 여러 장의 이미지를 나누어 처리하는 배치 기능도 지원합니다. 단어뿐 아니라 뜻, 예문, 유의어, 반의어를 추출하는 구성이어서 카드에 어떤 정보를 넣을지 먼저 정하는 것이 좋습니다.

이 순서로 시작하세요

  1. 사용할 단어장 텍스트를 붙여 넣거나, 읽기 쉬운 단어장 사진을 업로드합니다.
  2. 카드 앞면과 뒷면에 넣을 내용과 언어 등 구성 옵션을 선택합니다.
  3. AI로 스터디 세트를 생성하고, 단어와 뜻이 정확한지 살펴봅니다.
  4. CSV를 다운로드한 뒤 iPhone 또는 iPad의 굿노트로 가져옵니다.

결과를 검토하는 시간이 필요한 이유

사진의 기울기나 흐릿한 글자 때문에 단어가 다르게 인식될 수 있습니다. 예문과 유의어처럼 AI가 정리하는 내용은 원문과 대조한 뒤 학습에 사용하는 편이 좋습니다. 처음에는 한 페이지 정도로 시험해 보고 카드 구성이 원하는 형태인지 확인해 보세요.

이미지와 텍스트는 AI 처리를 위해 외부 서비스로 전송될 수 있습니다. 개인정보나 공유 권한이 없는 학습 자료는 입력하지 마세요. API 이용 조건과 비용은 사용하는 서비스의 설정에 따라 달라집니다.

굿노트로 가져올 때 확인할 점

저장소 안내 기준으로 굿노트 CSV 가져오기는 iOS와 iPadOS에서 지원합니다. 다운로드한 파일을 파일 앱이나 iCloud Drive로 옮긴 뒤 굿노트의 가져오기 메뉴에서 선택하는 흐름입니다. 앱 버전에 따라 메뉴 위치가 다를 수 있으므로 현재 사용 중인 굿노트의 가져오기 기능을 확인하세요.

이 글의 기준

공개 저장소의 README.md와 앱 설명을 바탕으로 정리했습니다. 앱의 기능과 외부 서비스 정책은 바뀔 수 있습니다. 이 글은 실제 이용 성과나 서비스 품질을 보증하지 않습니다.
