Gemini Argon Radar

실험용 모니터링 도구입니다. 모델의 공식 출시나 접근 가능성을 보장하지 않습니다.

목록의 변화에서 출발하기

Gemini Argon Radar는 Gemini API 모델 목록을 조회하고 새 항목의 등장을 관찰하는 웹 앱입니다. v1beta와 v1alpha 엔드포인트를 조회하고, 기준 목록과 비교해 달라진 항목을 표시하는 기능이 저장소에 소개되어 있습니다. 이름의 Argon은 검색 대상으로 설정한 키워드이며, 특정 모델의 공식 출시를 보증하는 표현은 아닙니다.

관찰과 테스트의 흐름

  1. 본인 계정의 API 키로 조회 가능한 모델 목록을 불러옵니다.
  2. 현재 목록을 기준점으로 저장하고 적절한 조회 주기를 선택합니다.
  3. 변경 항목의 ID, 설명, 지원 메서드를 확인합니다.
  4. 필요하면 플레이그라운드에서 간단히 테스트하고 공식 문서와 대조합니다.

목록에 보이는 것과 사용할 수 있는 것

모델 ID가 목록에 나타나더라도 실제 생성 요청의 권한이나 지원 메서드는 다를 수 있습니다. 저장소의 라이브 핑과 모델 테스트 기능은 이 차이를 확인하기 위한 수단입니다. 알림이나 강조 표시를 출시 소식으로 단정하지 말고, 계정의 접근 권한과 Google의 공식 안내를 함께 확인하세요.

너무 짧은 조회 주기보다 필요한 주기

자동 조회는 API 요청을 반복합니다. 용도에 맞는 주기를 선택하고 사용 한도를 살펴보세요. 브라우저가 백그라운드 탭의 실행을 제한하거나 PC가 절전 상태로 들어가면 감지가 지연될 수 있습니다. 테스트 경보는 실제 감지 기록과 구분해야 합니다.
