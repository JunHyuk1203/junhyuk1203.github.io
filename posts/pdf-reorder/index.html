원본을 보관하고, 결과의 실제 페이지 순서를 확인하세요.

앞면과 뒷면을 따로 스캔한 문서

자동 급지 장치인 ADF로 문서를 스캔할 때, 단면 스캔을 두 번 해서 양면 문서를 만드는 경우가 있습니다. 이때 앞면 묶음과 뒷면 묶음이 이어지면 읽는 순서와 파일의 페이지 순서가 달라집니다. ADF PDF Reorder는 이런 상황에서 스캔 페이지의 순서를 다시 맞추기 위한 웹 도구입니다.

파일을 넣고 재정렬하기

  1. 원본 PDF를 별도로 보관합니다. 재정렬 결과와 비교하기 위해 필요합니다.
  2. 앱의 업로드 영역을 클릭하거나 PDF 파일을 끌어다 놓습니다.
  3. 파일 이름을 확인한 뒤 순서 재정렬하기를 실행합니다.
  4. 결과 파일의 첫 장, 중간 장, 마지막 장을 원본 문서와 대조합니다.

어떤 문서인지 먼저 확인하세요

페이지 순서를 바꾸는 작업은 문서의 스캔 방식과 맞아야 합니다. 앞뒷면이 이미 교대로 들어간 PDF나, 한쪽 면의 누락이 있는 문서는 자동 정렬을 한 번 더 적용하면 원하는 결과가 나오지 않을 수 있습니다. 페이지에 인쇄된 쪽수를 확인하고, 작은 문서로 먼저 시험해 보는 방법을 권합니다.

브라우저에서 처리하는 방식

앱 화면은 PDF 처리가 브라우저 안에서 이루어진다고 안내합니다. 다만 외부 라이브러리를 불러오기 위해 인터넷 연결이 필요할 수 있습니다. 파일이 크면 기기의 메모리나 처리 성능에 영향을 받을 수 있으니 작업을 마칠 때까지 탭을 유지하세요. 스캔된 글자를 수정하거나 OCR로 텍스트를 추출하는 기능과는 용도가 다릅니다.

이 글의 기준

공개 저장소의 index.html와 앱 설명을 바탕으로 정리했습니다. 앱의 기능과 외부 서비스 정책은 바뀔 수 있습니다. 이 글은 실제 이용 성과나 서비스 품질을 보증하지 않습니다.
