휴대폰 파일을 전자칠판으로,
QR 하나로 이어 주기

케이블을 찾거나 메신저에 파일을 올리는 대신. Windows 전자칠판과 PC에서 파일을 받는 EasyUpload의 사용 흐름을 살펴봅니다.

j.JunHyuk12032026. 10. 27.3분 읽기
EASYUPLOAD↥휴대폰에서 PC로, QR 파일 전송
EasyUpload

Windows에 설치하는 앱입니다. 다운로드 버튼은 공식 GitHub Releases로 연결됩니다.

파일 하나를 옮기려는 상황

전자칠판에서 휴대폰에 저장된 자료를 띄우고 싶을 때, 파일을 중간 서비스로 보내거나 케이블을 연결하는 과정이 번거로울 수 있습니다. EasyUpload는 Windows 전자칠판과 PC에 설치해 사용하는 백그라운드 파일 수신 프로그램입니다. QR을 통한 업로드를 중심으로 기기 사이의 전달 과정을 구성합니다.

설치형 프로그램이라는 차이

이 앱은 브라우저 링크를 여는 것만으로 수신기가 실행되는 형태가 아닙니다. GitHub Releases에서 EBoardReceiver_Setup.exe를 내려받아 대상 Windows PC에 설치해야 합니다. 저장소에서는 PC 부팅 시 자동 시작과 트레이 아이콘 대기를 주요 기능으로 설명합니다.

파일을 받기까지

  1. 수신할 Windows PC에서 공식 저장소의 Releases를 확인하고 설치 파일을 실행합니다.
  2. 설치한 수신기를 시작하고 QR 업로드 접속 정보를 확인합니다.
  3. 휴대폰으로 QR을 열어 파일과 사용자 지정 파일명을 입력합니다.
  4. PC에서 파일이 도착했는지, 이름과 내용이 맞는지 확인합니다.

이름과 연결 방식 확인하기

업로드 시 파일명을 지정하도록 되어 있으며 한글 파일명과 중복 방지를 지원한다고 안내합니다. 여러 사용자가 자료를 보낼 때는 발표 순서나 자료 제목을 포함해 이름을 정하면 파일을 구분하기 쉽습니다.

외부망 접속은 Cloudflare Tunnel을 이용합니다. QR 주소를 가진 사람이 접근할 수 있는 범위를 확인하고 필요한 사람에게만 공유하세요. 기관이나 학교에서 사용할 경우 해당 네트워크와 파일 반입 정책도 함께 확인해야 합니다.
